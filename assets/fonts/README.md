# Local fonts

Golos Text variable weights 400–900 and Unbounded weight 800 are served locally.
The Latin, Cyrillic and Cyrillic Extended subsets cover the site's RU/KZ/EN text.
Downloaded from Google Fonts on 2026-10-12, using the CSS API:

https://fonts.googleapis.com/css2?family=Golos+Text:wght@400..900&family=Unbounded:wght@800&display=swap

Both fonts use the SIL Open Font License. Original license texts are included in
Golos-OFL.txt and Unbounded-OFL.txt. No external font requests run in the site.
